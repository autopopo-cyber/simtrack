### 障碍场攻坚修掉的锁死/碰撞根因（全部实测定位）
1. **估计矛盾解锁**：直通道方位角展开不足 15° 无法重三角，病态三角把终点估计锁在
   错点 16m → 狗在错点"到达"（19.46m 误判）。狗到估计 3.5m 内但针孔距离明显更远时
   用当前观测点重估解锁（越界观测不采纳）；到达①加针孔 <4.5m 交叉验证。
2. **DWA 贴脸全碰撞假死锁**：障碍贴进 0.8m 排斥圈 → 所有轨迹起点都在圈内 → 全碰撞
   None → STOP 每步刷 bounce 永冻。修复：0.1s 反应宽限 + **动态全碰撞时返回"最小障碍
   距离最大"的逃逸轨迹**（静止等待会被 1m/s 障碍真撞上，collision 161 的教训）。
3. **接触区豁免**（移动障碍场）：障碍命中格距狗 <0.5m 时主动标 FREE（标 WALL=永冻
   812 碰撞；留 UNKNOWN=幽灵泡游荡）；collision 812 → 24（一次 0.12s 擦碰）。
4. **爬出禁入区**：墙在狗停下后被标到其邻格 → 自己格 blocked 永冻（bounce#1530）→
   前方净空 >0.15m 时允许 ≤1.5m/s 爬出（0.5m/s 会被 1m/s 障碍顶牛）。
5. **bounce 节流**：两次 bounce 至少隔 40 步——每步重转让狗走不出 1cm（角点 bounce#1680）。
6. **目标格吸附**：终点格被移动障碍临时标记 → HPA 细层目标在标记团里，A* 扩 15 万格
   失败 → PLAN-FAIL 死循环 → 就近吸附可达格（标记随障碍移走消退）。
7. **近距检测盲区**：360p 下球 <2.5m 超出相机视野 → 到达窗口 50→200 步，
   阈值按 bob/偏帧噪声放宽（②针孔 <4.0）。

## 六、"收窄不可通行余量" A/B 实验（主人思路实测）

主人观察：弯道障碍旁"明明还有很宽的道路，狗却要挤过去" → 提出只留 10cm 防撞宽度、
其余额外余量全取消。实测 A/B（混合全障碍场）：

| 配置 | 步数 | bounce | 到达距真值 |
|---|---|---|---|
| 基线（keepout 0.05 + 门 wd>2 + 前沿 5×5 + DWA r+0.2） | 41560 | **93** | **3.19m** |
| keepout 0.10+对角禁入 | 中途杀 | ~155（前半程即翻倍） | — |
| 门过滤 wd>1 + 前沿 3×3 | 59120 | **1830** | 3.07m |

**结论：不行。** 附加余量是"门质量"的承重墙——收窄后规划器把墙根/窄缝当门，
狗被反复引进 STOP/bounce 陷阱（bounce 恶化 20 倍）。宽路利用率低不是余量问题，
是**弯道障碍摆在弯心**把 4.9m 转弯区分成两条 ~1.7m 缝。对症修复：
**弯道障碍贴外侧墙**（右弯 x=48.5 / 左弯 x=1.5）——内侧留出 ~3.3m 宽转弯通道，
障碍仍在拐弯处但不妨碍转弯走线。

保留的 10cm 项：DWA 障碍排斥 r+0.3（=碰撞边界 0.7 + 10cm，正是主人要的防撞宽度）。

### 附带根修：DWA"贴脸全碰撞"假死锁

- 现象：移动障碍贴到狗 0.8m 排斥圈内（物理未撞，collision 0），DWA 所有轨迹起点
  都在圈内 → 全碰撞 None → STOP 每步刷 bounce，escape 被 bounce 清零速度 → 锁死
  （实测 bounce#1900+ @(19.4,19.0)，前方 4m 畅通）。
- 修复三件套：①障碍判定加 0.1s 反应宽限（前 2 采样不判——已贴脸时允许拉离）
  ②DWA-None 事件只在**移动中**才进 STOP 分支（静止时不再 bounce 刷屏）
  ③DWA 未给速度时 v_des=0 安静等待（不用目标距离速度盲目加速）。

## 八、门宽度判断（主人 2026-08-10 指令）——✅ 已完成
主人对第六节 A/B 的回示：**不要做"收窄余量"本身，要做"窄缝识别"**——

- 现实中有大量能透过激光、但狗过不去的窄缝/栅栏；算法应**有效识别**这类陷阱，
  而不是靠附加余量把它们糊掉。
- 地图边缘要**精确**（墙、障碍是什么形状就建什么形状）；精确带来的问题
  （规划器把墙根/窄缝当门 → 引进 STOP/bounce 陷阱）应当**正面解决**，
  而不是靠模糊地图回避。
- 落地（对齐 ROS costmap 分层思想）：占据栅格保持精确（不占不膨），
  **通行性判断放到规划层**——PASS 净空场（距已知墙 <0.6m 的格不可规划，
  宽 <1.2m 的缝自动封闭）+ 门验收 clear_ok。第六节"收窄恶化 20 倍"的根因
  重新诊断为：那次是把门质量门槛**往下放**（方向反了）；门宽度判断是往上提。
- **结果：四场景 bounce 69→1 / 50→0 / 37→3 / 15→2，混合场擦碰 24→0，
  物理时间 123~153s（纯墙逼近 120s 极限）**。回归还暴露并根修了跳步粒度奇偶
  预埋 bug（直奔 beeline 落不上目标格 → A* 风暴瘫痪；基线靠运气没踩中）。

## 九、障碍视觉 mocap 修复 + 弯道障碍随机化（2026-08-10 主人观察驱动）

主人看录像发现两个问题：①10 个直道障碍"没在动"、全在段中央一列齐排；
②9 个弯道障碍刚性贴 x=48.5/1.5 太整齐。排查+修复：

1. **障碍视觉冻结 bug（根修）**：障碍在 MuJoCo 里是无关节静态 body，`xpos` 从不随
   `obs_world` 更新——**逻辑上一直在动**（雷达/碰撞/DWA 感知真位置，回归成绩是真的），
   只是渲染 frozen。修复：障碍 body 全部 `mocap="true"`，每 tick `sync_obs_mocap()`
   同步（contype=0 无物理副作用）。顺带把移动障碍初始位置从"全在 x=25 段中央"
   改为段内种子随机。
2. **弯道障碍种子随机化**：`mix_bend_positions(seed)`——右弯 x∈[47.6,48.6] /
   左弯 x∈[1.4,2.4]，y=5k±1.5。**随机范围必须贴外墙半侧**：首版放到口袋中间
   （x=46.9）把转弯区切成两条 ~1.3-2.0m 紧缝 → 执行层穿缝 bounce 风暴（实测 404）——
   收窄后两侧走线都 ≥1.9m。
3. **接触区豁免盲区根修（随机化钓出的预埋大 bug）**：弯道障碍进口袋后，狗贴近它时
   接触区豁免（为移动障碍设计的防冻结机制）把**固定障碍**命中格也标 FREE → 地图把
   固定障碍从狗身边擦掉 → 狗开进障碍体内卡 7700 步（collision 8127）。
   修复：豁免只对移动障碍生效（`_moving_obs_positions()`），固定障碍贴近保持 WALL
   （安全圈+刹车兜底，固定×20 场正是 collision 0 的证据）。

**最终成绩（混合全障碍，seed7，无特权，二维码 10/10）**：
到达 4.24m，40600 步（物理 203s / 墙钟 255s），bounce 35，**collision 0**。
代价结构：每弯 1-2 次"边界缝探测→无进展→拉黑→走宽侧"（缝宽 1.0~1.6m 边界区的
合理行为），比刚性对齐布局（152s/bounce 1）多 ~50s。
新录像：`scans/firefly_mix_v2.mp4`（障碍可见移动 + 弯道随机分布）。
