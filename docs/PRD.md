## 一、产品目标（主人定义）

**机器狗自主进入一个未知屋子并完成导航**：
- 面积 **<300㎡**，房间布局随机
- 地面可能有障碍物（家具/杂物，低矮）
- 必要时通过**窄通道**——60cm？80cm？**越窄越好**（实测下限见验收表）
- 从进门到完成探索/到达目标点，全程自主（SLAM + 探索 + 避障 + 导航）

**最终交付**：Unitree A2 实机（RK3588 算力，4D LiDAR L2 前后双装）。

## 二、目标硬件（实机 spec，2026-08-14 主人提供）

| 部件 | 规格 | 对导航栈的意义 |
|---|---|---|
| **Unitree 4D LiDAR L2**（前后双装） | 360°×96° FOV，非重复转镜；10m@10%反射 / 30m@90%；±3cm；21600点/s有效（双装≈4.3万）；0.05m 盲区；100Klux 抗强光 | 仿真设计点 `LIDAR_RANGE=10 LIDAR_NOISE_M=0.03`（暗面家具全场景保守值） |
| L2 内置 3 轴 IMU + **POINT-LIO** | 单传感器 LIO 里程计 | **常规层直接用 LIO 输出当 /odom**（漂移 ~0.1-1% 行程）；腿式 5% 漂移模型=容灾层（LIO 挂了） |
| 96° 垂直 FOV | 能看见地面 | **地面障碍物靠它**——真机管线需 pointcloud→laserscan 的 **z 带切片（建议 10–40cm 带高**，覆盖腿部碰撞高度）；仿真尚未覆盖（待办） |
| 接口 ENET UDP / TTL UART | — | 真机集成需 UDP 桥节点（待办） |
| RK3588 算力 | 4×A76+4×A55，NPU 6TOPS | 2D SLAM 全栈单 A76 核就够（旧 PRD §8.1 调研结论仍有效）；瓶颈在步态+感知融合，不在 2D SLAM |

## 四、非目标（明确不做）

- ❌ 3D/多层/台阶（纯 2D 平面假设）
- ❌ 人群语义（障碍按刚体处理）
- ❌ 刻意造机器人无法识别的场景（玻璃墙/纯白墙）——主人原则
- ❌ <0.5m 通道（0.4m 躯体两侧各 5cm，本体公差都不够）

## 五、主人原则（铁律，跨时期不变）

1. **不作弊**：决策层零真值——定位/速度估计/地图确认不得读仿真真值（2026-08-12 整改闭环；
   ROS2 时期 `/true_pose` 只作测量诊断，frame_id 刻意叫 "true" 防误用）
2. **零碰撞**：运动学约束保证（现实中不允许碰撞）
3. **探索哲学**（2026-08-09 主人定义）："每个门都可能是疑似终点，探索 = 确认门后到底是什么"
4. **多测是最高产的 bug 探测器**（换种子/换布局/看录像）
5. **先写文档再写代码**（深水区）；负结果必须记录（否决实验见踩坑文档）

## 七、下一步（优先级）

1. **对门行为**：路径穿两侧墙距<1m 的点 → 门前 0.5m 停 → 旋转对齐（轴线⊥门面 ±5°）→ 降速 0.2m/s 穿越。把 0.6m 变任务级，顺手治"门舞"（贴墙试探=退化几何暴露=地图变形）
2. **goalshape300 迷宫**：~300㎡ 不规则房间，最终验收场（目标尺度回环机会更少，定位条件不同）
3. **地面障碍物**：仿真多平面扫描（模拟 L2 96° 垂直 FOV）+ z 带切片管线
4. **真机集成**（新 ament 包，不开新仓库）：L2 UDP 桥（POINT-LIO odom）、z 带 pointcloud_to_laserscan、EKF（robot_localization）、Unitree 步态桥
5. 小项：`record_traj.py` slam 列 bug（TODO）；CORRECT_PERIOD_S=15 参数扫描（低优先）

## 八、术语表（速查）

| 术语 | 含义 |
|---|---|
| 漂移抽签 | OdometryDrift 按 seed 一次抽定的 scale 符号+yaw 偏置（同 seed 可复现） |
| 自建图重定位 | CORRECT_REF=map：对 slam 自己建的 /map 做相关匹配重锚里程计（土法 AMCL，真机可复现） |
| 仿真特权修正 | CORRECT_REF=true：对真迷宫高度图匹配（仅实验上限参考，真机无此图） |
| 门舞 | 狗在墙前/门前反复蹭动找不到通过点的行为；=退化几何暴露=地图变形诱因 |
| 雪球效应 | slam 回环只在 loop_search_maximum_distance(已调 7m) 窗内找候选，漂移超窗永不回环 |
| A* 推进 | goal_runner 的 free=1/unknown=8/墙=∞ 规划器，子目标取连续 free 段末尾（前沿） |
| L2 设计点 | LIDAR_RANGE=10 + LIDAR_NOISE_M=0.03（暗面 10% 反射全场景保守值） |
