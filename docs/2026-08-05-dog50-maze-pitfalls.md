## 一、核心设计原则（主人指令，不可违背）

| 原则 | 内容 |
|---|---|
| **碰撞=0** | 现实中不允许碰撞。不靠物理碰撞挡（slide直驱不可靠会穿墙），靠**运动学约束**：前瞻测距 + 制动约束 v≤sqrt(2·A_DECEL·d) + 加速度限制 + 预判转向 |
| **不作弊** | 真实地图未知，从头扫描。A* 必须用 SLAM grid，**禁止用世界真值规划**。UNKNOWN 可通行但代价高（traversable + UNKNOWN_PENALTY=8），执行层撞墙写回 WALL |
| **效率** | 50m 小地图不该走几十万步。参考成熟 frontier_exploration：门聚类/评分/换门/去噪 |

## 二、卡死三连环 bug（墙边场景）

1. **scan 墙前膨胀**：`gset(prev, WALL)` 把机器人脚下格标 WALL → find_gates 起点失败 → 空门。修复：墙前格标 FREE。
2. **find_gates 起点过严**：贴墙时 walkable=False → 空门 → 原地 bounce 死循环。修复：起点放宽 `gget!=WALL` + `_nearest_walkable` BFS 脱困。
3. **主循环 path=None 只 _bounce 不 step**：永不移动，stuck 检测不触发。修复：path=None 调 `mv.step(FINISH)`。

## 三、迷宫赛道结构（关键！）

50m 蛇形赛道**不是简单蛇形走廊，是迷宫**：
- 10 段水平走廊（y=2.5+5k），段间墙**有缺口**（y=15.0 缺口在 x<4.1）
- 连接段（x≈2.5/47.5）有横向段间墙，缺口窄（~10° 视角，如右侧 y=9.3-10.6 缺口在 x≈46）
- **`_bounce` 候选必须每 5° 扫 360° + 推进评分**——稀疏角度（±[10,20,35,...]°）漏掉窄缺口是卡死主因

## 四、探索效率 8 项改进（commit 1a03d58）

1. 门聚类质心 `cluster_gates()`：200 单格 → 4-10 region
2. `pick_gate` score 模式：`0.55·advance + 0.25·(1/dist) + 0.20·(size/50)`（终点导向）
3. `traversable()`：UNKNOWN 可通行 + UNKNOWN_PENALTY=8
4. 失败换门：A* 失败试下 3 个
5. `back_blacklist`：BACK 过没新门的路标跳过
6. 碰撞检测用真实几何 `is_obstacle_world`（0.7m）非 blocked()（0.9m 假阳性）
7. Mover 硬防穿墙 + 撞墙写回 WALL
8. `_bounce` 每 5° 扫 + 推进评分（`dot·2 + min(d,4)`）

## 六、提速实验（2026-08-05，4m/s）

主人问"最大速度提到4m/s有用吗"。实测结论：**有用但效果有限**（瓶颈在 bounce/探索不在直线速度）。

| seed | 2m/s 版 | 4m/s 版 | 变化 |
|---|---|---|---|
| 7 | ✅ 728s / 21.3万步 | ✅ 649s / 18.3万步 | -12% 时间，-14% 步数 |
| 170456 | ✅ 768s / 23.9万步 | ⏳ 700s 差3m | 接近持平（bounce 221→252） |

**关键组合改动**（commit 4c34c8b）：
1. SPEED_MAX 2→4, A_ACCEL 3→5, A_DECEL 5→8
2. **YAW_RATE 保持 1.5 不提高**——第一次试 2.5+4m/s 窄缺口过冲卡死（7万步卡连接段）
3. **近墙限速**：`d_clear < 2.0m 时 v_des ≤ 1.5`——开阔跑 4m/s，狭窄处自动减速防过冲

制动距离验证：v=4, A_DECEL=8 → v²/2a = 1.0m < LOOKAHEAD 4.0m ✅ 安全。

**教训：光提速度没用，必须配合"近墙限速"**——真实机器人行为：开阔提速、狭窄减速。

## 八、双层地图 + 射线清除（2026-08-05 10小时目标）

主人 10 小时目标：①探索效率 ②已知地图+障碍变化快速寻路（走中间）③随机位置绑架恢复。

### 性能元凶（重大发现）
- **EGL 离屏渲染 3.5 秒/帧**（llvmpipe 软件渲染，与分辨率无关）——视觉识别每 40 步渲染一帧会把导航从 14.9万步/s 拖到 ~10步/s！
- **解决**：视觉默认关闭（`--vision 1` 才开），标牌几何默认关闭（`--landmarks 1` 才开）
- 教训：**渲染类功能必须默认关**，否则拖死核心算法

### 双层地图（借鉴 ROS costmap 分层）
- `static_grid`：旧地图背景（只读），`KNOWN_MAP_MODE` 时规划叠加
- `gget_plan()`：规划视图 = static 墙永远 WALL + live 障碍/自由优先
- `scan()` 加**射线清除**：射线穿过格强制 FREE（旧障碍被"照"掉），命中格 WALL
- 解决"已知地图+障碍变化"：旧障碍位置新扫描自动清除，static 的墙不受影响

### 走中间 Voronoi 代价
- `VORONOI_C=2.0`：KNOWN_MAP_MODE 下 A* 代价 + C/d²（d=离墙格数）
- 贴墙爆炸、中线最低——路径自然贴通道中线

### 新参数
- `--save-map <npz>` 阶段1保存地图 / `--load-map <npz>` 阶段2加载
- `--random-start 1` 绑架随机起点（避开墙/障碍） / `--target start|finish`
- `--obs-reseed <step>` B阶段运行中障碍变化
- `--vision 1` / `--landmarks 1` 视觉/标牌（默认关）

### 标牌贴墙（主人"别堵路"）
- 标牌贴**段尾横墙内壁**（x=49/1 交替），机器人沿 x 正对可见
- 侧墙标牌不可见（相机朝前看不到 y 方向墙）——正前方横墙才可见
