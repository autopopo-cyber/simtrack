## 四、下一步（主人方向）

### 疑似终点机制（主人 08-09 定义，替代"终点发现"）
**每个门都可能是疑似终点**——探索的本质是确认门后到底是什么：
- 门 = 未知前沿 = **疑似终点候选**
- 走向门 → **确认门后**（新区域 / 死胡同 / 终点）→ 记录确认结果
- 确认过的门 = 已知（不再疑似）；未确认的门 = 下一个疑似终点
- 实现方向：pick_gate 时门后探测（地图边界出口 / FINISH 邻接 / 开阔区域），疑似终点门优先
- 语义修正：不是"检测到终点就冲"（确定性），是"每个门都是候选，确认过程即探索"
