# 无特权化攻坚二：终点发现 + 探索链路根修（2026-08-09）

> 主人指令：不许作弊，只用摄像头+激光雷达走到终点（探测到终点就该知道那是终点）。
> 前情：2026-08-09-noprivilege-status.md 记录的卡死（37.4% 卡 ch2）。

## 一、根因清单（全部实测定位）

### A. 幽灵门（最大元凶）
- **雷达沿射线 0.1m 步进采样，会跨过 <0.1m 真缝**：U 型弯 45° 斜边（实测厚 0.11-0.14m）
  端点与墙端之间的亚格子缝隙 → 射线穿缝把墙另一侧标 FREE → 不可达的"幽灵门"
  永远吸引狗（pick_gate 的 advance 朝终点方向评分加成）。
- **bad_gates 黑名单 key 错位**：存的是聚类质心，find_gates 过滤的是原始门格 →
  黑名单形同虚设（原始 firefly 就有，作弊模式碰不到所以没暴露）。幽灵门无限重选，
  实测 bounce 412 次卡 202s 直到超时。
- **GATE-STALL 换门即清零 + 质心漂移** → 无进展计数形同虚设。

### B. 探索模式安全圈不可见
撞固定障碍写的 0.8m 安全圈在 static 层，但 `gget_plan` 探索模式不读 static →
规划器永远看不见圈 → 路径反复穿同一障碍。

### C. find_gates BFS 两个结构病
- **虚空漫游**：无地图边界检查，BFS 从缺口/边界漫游到地图外 UNKNOWN 虚空
  （实测 visited 5099 格漫到 x=72m，真门一个没找到）。
- **跳步飞越过渡格**：2m 大跳的中间格不进 visited → FREE→UNKNOWN 过渡格永远
  评不到门；直接补录时又忘了写 came_from → fine_path 断链 → 路径只剩 1 格
  直冲穿墙（实测 path=1 撞墙 bounce 风暴）。

### D. 执行层 bounce 自维持死锁
- 候选方向净空 0.40m（恰过 STOP_MARGIN）就能选 → 目标对齐评分 dot*4 把狗一遍遍
  送进贴墙方向；escape 目标 = 上次 bounce 方向 → 自维持。
- 修复：逃逸方向净空必须 ≥0.8m，否则走随机最远兜底。

### E. 门质量
- 测距限界（30m）射线稀疏 → 前沿天然 1-3 格斑点簇；dyn_min=8 全过滤 → 保底只选
  "最近门"（评分失效）→ 系统性送进口袋死角。修复：dyn_min 2-3 + 保底返回全部原始
  门格让评分选。
- 门只认"开阔前沿"（未知格 3x3 无墙）：墙缝/墙根/角落后未知是射线永远扫不到的
  陷阱，不是门。
- 门即达：狗到路径终点 1.8m 内即消耗（雷达早扫过门后），不强踩墙根门格
  （每个墙根门硬踩 = STOP+bounce 风暴 5-7s，全程 15+ 次）。

### F. 墙角困住恢复
连续 3 次强制重规划位置不动 → 回退最近可达路标（跳过 <1.5m 的脚边路标——
实测路标在脚边时回退空转）。

### G. 视觉性能（本机实测 18 步/s 元凶）
场景没放标牌时 ArUco 金字塔（6 尺度含 3x 放大 4K 图）每帧白跑 → 场景无标牌时
（--landmarks 0）跳过 ArUco，终点球检测不受影响。

## 二、终点发现（修复 #5，主人核心要求）

**每个门都可能是疑似终点；一旦某扇门后确认是终点，探索就结束直奔它。**

- `test_scripts/finish_detect.py`：相机帧绿色终点球检测（RGB 阈值 + 最大连通块），
  方位角 + 距离（针孔模型，R=1.5m）。
- **三角定位**：标牌背景板会遮挡终点球（实测只剩 10-16% 面积 → 尺寸法距离偏远 3 倍），
  改为多帧方位角最小二乘三角定位（方位角抗遮挡），近距离面积法兜底。
- **到达判定无特权**：狗到"自己的终点估计"3.5m 内，或当前帧 blob 面积 >25000px
  （球在 4-5m 内近在咫尺）。真值距离只进成绩单评分。
- **pick_gate 去特权**：未见终点时方向项 = 朝向保持（沿走廊继续走，无特权）；
  见到终点后方向项朝终点估计（合法，亲眼所见）。
- EXPLORE-DONE 切 KNOWN_MAP 只在 finish_est 存在时（切了才知道去哪）。

### 二维码 + 里程计辅助定位（主人问"能不能用起来辅助"）

**二维码还在**：10 个 ArUco 标牌（每通道 1 个，`landmarks.py`），默认开。
本轮让标牌参与导航——作为里程计绝对修正锚点（`--odom 1`）：

- `simtrack/odometry.py`：带噪里程计（线速度比例噪声，默认 2%），决策/建图/避障全用估计位姿
- 看到标牌 N → 由标牌已知位置（环境设施，真实世界路牌同理）+ 方位/距离反解狗位姿 →
  指数加权拉回；标牌近似正面时还能修正朝向（偶通道朝 -x、奇通道朝 +x 是环境先验）
- 修正几何离线验证：反解位姿误差 0.33m
- **实测结论（诚实）**：
  - 2% 噪声：漂移被修正压到 ~1m，但硬栅格地图无法吸收位姿误差——墙被重复标在不同
    偏移处（双重墙/走廊变窄），狗在墙根陷阱卡死
  - 0.5% 噪声 + 近距墙标记（12m 内才标墙）：明显好转但仍会在长通道墙根停滞
  - **能用起来的前提**：需要扫描匹配（ICP/scan-matching）或概率占据栅格让地图容忍
    位姿误差——这是下一步的活。机制代码已就位（--odom 1 / --odom-noise），验证脚本可复现

### 终点发现的三次实测陷阱（逐一定位修复）
1. **背景板遮挡**：ch9 标牌的背景板挡住终点球大部分面积 → 尺寸法距离偏远 3 倍
   （42.5m 实测报 105.7m）→ 改多帧方位角三角定位（方位角抗遮挡）。
2. **病态三角**：同一视角反复看（射线近重合）最小二乘乱飞，曾把估计打到狗脚边
   误判到达（距真值 3.84m 时 est 误差 10m+）→ 基线>3m + 角度展开>15° 才采用。
3. **隔墙偷看**：ch8 隔 1m 墙看到球顶，面积判定提前触发/估计在墙后 → 到达判定加
   "感知地图视线可达"（line_clear），**越界估计不参与门评分**（否则狗被吸在墙根死循环，
   实测 5.3 万步）——看不到=继续沿走廊探索，绕进 ch9 后干净看到 → 收敛到达。
