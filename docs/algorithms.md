# 关键算法说明

> 会话恢复速查。最后更新 2026-08-14。每个算法附"实测教训"——这些数字是用实验换的，别丢。

## 1. OdometryDrift 足式里程计漂移模型（sim_bridge.py）

```
scale_f = 1 + U(-pct, pct)        # 一次抽签固定符号（标定误差），seed可复现
yaw_bias = U(-1,1) × bias_deg     # 陀螺零漂，常值
每步: vx' = vx·scale_f + N(0,σv);  ω' = ω + yaw_bias + N(0,σw)  → 积分位姿
```
- 输入是**真实达成的机身速度**（真值差分），代表里程计实测。
- **教训**：ODOM_DRIFT_PCT 单位是百分比（5=5%），曾被当成小数喂过（scale_f=2.25 的鬼漂移）。
- 真机对应：L2 的 POINT-LIO 漂移 ~0.1-1% 行程——本模型对应"LIO 挂了"容灾档。

## 2. 相关扫描匹配（两套，别混）

**A. 对自建图**（`sim_bridge._scan_match_map`，诚实版=土法 AMCL）：
从漂移 odom 初始位姿出发，两层搜索（粗 ±1.5m/±20°, 11³ → 细 ±0.2m/±4°, 7³），
评分 = scan 端点落在 /map 墙格(data≥65)的个数。行约定 **no-flip**（row=(y-oy)/res，实测验证）。
**得分<40 拒绝修正**（该区域建图不足，往烂图上锚=锚错）。~0.2s/次，30s 一次可接受。

**B. 对真迷宫图**（`sim_server.scan_match`，仿真特权版，仅实验上限参考）。

**实测**：对自建图命中 mean 266-303/360；噪声 ±3cm 几乎不减命中（5cm 栅格+多视角墙厚吸收）。

## 3. 周期重定位（_correction_cb）——修正机制

每 30s：匹配 → **硬重置**漂移里程计到匹配位姿（跳变式，非 EKF 软融合）。
- **机理证据**（修正量对账法）：yaw 修正量 mean 1.5°/次 ≈ 偏置 0.05°/s × 30s——精确抵消累积；
  pos 修正量累计 ≈ 不修正时本会漂掉的量（同 run 反事实证据）。
- 效果：无 IMU 最坏工况 8.5m 失控 → 有界（15m 基线 1.98m；L2 参数+健康驱动 0.52m）。
- **误差下限 = 地图局部变形**（修正把 odom 钉到地图系，地图歪哪 odom 继承哪）。

## 4. A* 推进（goal_runner._route_step）——探索驱动核心

```
代价: free=1, unknown=8(可穿但贵), 墙=∞, **地图数组外=unknown**(不是错误!)
规划 dog→waypoint 的 A*(启发=欧氏,搜索盒=两点bbox±3m)
子目标 = 路径上"从狗出发连续 free 段"末尾（=前沿）
  → 门已知: 路径自然穿门(free便宜); 门未知: 乐观穿虚空,子目标落前沿,狗推进→图长→重规划
  → free段<0.8m时允许子目标越入unknown 1.5m（NavFn对近距离unknown目标没问题）
NavFn 对 free 子目标必成功 → 整个驱动无死锁
```
三代失败品（勿回退）：原地等地图死锁（静止狗图不长）→ 扇形贴墙振荡（3m短视）→
BFS closest-to-waypoint 墙前鞍点（绕行两侧对称）。**教训：目标函数若不知门在哪，不能用直线距离评绕行收益。**

## 5. 墙抖动破对称（maze_gen.wall_jitter=0.5）

网格房间迷宫有 4 重旋转对称 → scan-match/回环锁错副本。抖动每条内部墙线位置 ±0.5m
（边界固定）→ 每房形状唯一。**这是环境设计解算法无解的问题**（纯2D几何SLAM解不了对称歧义）。

## 6. slam_toolbox 调参（为什么改）

| 参数 | 默认→改后 | 原因 |
|---|---|---|
| loop_search_maximum_distance | 3→7 | **雪球效应**：漂移超窗→真回访点落窗外→永不回环。窗放大让它追得上 |
| minimum_travel_distance | 0.5→0.3 | 关键帧更密，回环候选更多 |
| loop_match_minimum_chain_size | 10→4 | 早回环 |
| coarse/fine response | 0.35/0.45→0.22/0.32 | 降阈值让回环敢触发 |

## 7. Nav2 配置要点（nav2_fast_params.yaml）

- NavFn `allow_unknown: true`（探索必须穿 unknown 规划）+ `tolerance 0.5`
- **robot_radius 0.22**（圆）：0.8m 门在 costmap 有 0.36m 可通行带；0.6m 有 0.16m——**规划层不是窄门瓶颈，物理对准才是**
- MPPI iteration 1→3, vx_max 0.7（提速 4-7×）；velocity_smoother 限幅同步放开
- 恢复行为：清 costmap+旋转——注意清空窗内规划可能再失败（循环），换目标比等恢复快

## 8. 窄门通过性（实测标定）

狗足迹 0.8×0.4m 胶囊（过门起作用的是 0.4m 宽度）：
| 门宽 | 每侧余量 | 对准容差 | 实测 |
|---|---|---|---|
| 1.5m | 0.55m | ±68° | 无感通过 |
| 0.8m | 0.2m | ±28° | 任务级（零重试全速） |
| 0.6m | 0.1m | **±14°** | 碰运气（1过1卡4试4败）→需"对门"行为 |
对准容差 = atan((门宽-0.4)/0.8)——机身轴线与门法线夹角超容差,对角线宽>门宽,物理卡死。

## 9. 两条实测"定律"（最重要，跨算法有效）

1. **误差下限 = 退化几何暴露时长，不是传感器**：传感器变差(15m无噪→10m±3cm)结果反而好20倍
   （mean 1.81→0.08m）——因为跑得健康的狗一直在二维富几何环境。走廊/贴墙=不可观测方向积累。
   对策排序：探索模式(防退化暴露) > 修正频率 > 传感器参数。
2. **贴墙试探（门舞）= 退化几何暴露 = 地图变形**：同一行为的三副面孔。治门舞同时治定位损伤。
