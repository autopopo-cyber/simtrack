## 二、ROS 调研结论（已委托子代理调研，2026-08-05）

| ROS 组件 | 解决什么问题 | 借鉴点 |
|---|---|---|
| costmap 分层（static_layer + obstacle_layer + inflation_layer） | 旧地图障碍过期 | **射线清除**：传感器扫过的区域强制 FREE，旧障碍位置自动消失；static 只存永不变的结构（墙） |
| obstacle_layer 的 `track_unknown_space` | 未知区代价 | UNKNOWN 有独立代价（已实现 UNKNOWN_PENALTY=8） |
| AMCL `alpha_slow/alpha_fast` | 绑架检测 | 短期似然显著低于长期 → 注入随机粒子重定位 |
| Voronoi/GVD 骨架（代价 1/d²） | 走通道中间 | A* 代价加"远离墙"项：`penalty = 1/d²`，d=到最近墙距离 |
| frontier_exploration 信息增益 | 探索效率 | 目标点打分加"可新扫面积"项；目标保持机制防抖动 |
| navfn/global_planner 势场 | 全局规划 | 0.1m×50m 迷宫几十万格，Dijkstra 重跑毫秒级——障碍变了**整图重规划**即可，不需要 D* Lite |
| move_base 双 costmap + recovery | 组合 | 全局规划（大、静态+实时）+ 局部规划（小、只信实时）；失败 recovery：清地图→旋转→重规划 |

## 三、A 阶段设计（主线，先做）

### 3.1 双层地图（借鉴 ROS costmap 分层）

当前 `grid` 是单层 dict（UNKNOWN/FREE/WALL），scan() **只写不擦**——旧障碍标 WALL 永久残留。

改造为双层：
- **`static_grid`**：探索阶段保存的旧地图。含墙（hfield 结构）和旧障碍。**只读**，作为"背景"。
- **`live_grid`**：实时障碍层。每次 `scan()` 更新，用 **射线清除**：
  - 射线从机器人出发，沿方向逐格前进
  - 射线穿过的格（除了命中的那格）→ 强制 `FREE`（不管之前在 live_grid 是什么——旧障碍被"照"掉）
  - 射线命中的格 → `WALL`（当前障碍）
- **规划用叠加**：`effective(vx,vy) = static_grid(vx,vy) if static 是墙 else live_grid(vx,vy)`
  - static 的墙永远保留（结构不变）
  - 障碍位置以 live 为准（实时更新）
  - 旧障碍不在 live 里 → 规划时视为可通行

**代码影响**：
- `gget/gset` 改为操作双层（或保留单层接口，内部叠加）
- `scan()` 加射线清除逻辑（原来只标 FREE 当 UNKNOWN，现在强制 FREE）
- `is_obstacle_world()` 不再用于规划（那是世界真值作弊）；规划只用 SLAM 双层地图

### 3.2 走通道中间（Voronoi 代价）

当前 A* 代价：`WALL_PENALTY`（贴墙 2m 内惩罚 3）。不够"居中"。

改造：代价加 **Voronoi 项**：
```
d = wall_dist(vx, vy)   # 到最近墙的格数（已有 wall_dist）
penalty_center = C / (d*d)   # 贴墙代价爆炸，中间代价低
```
- C 取经验值（如 2.0），配合现有 WALL_PENALTY
- 效果：A* 自然沿通道中线走，不贴墙——参考 Voronoi/GVD 骨架
- **执行层不变**（Mover 运动学约束照旧，前瞻测距 + 制动约束，碰撞=0）

### 3.3 已知地图快速寻路（两阶段）

**阶段1（探索建图）**：
- 现有探索流程跑一遍（或加载已有地图）
- `--save-map` 参数：跑完把 static_grid 保存到 `scans/map_<seed>.npz`
- 保存内容：墙格集合（hfield 结构）+ 旧障碍格集合（可选，反正会被射线清除）

**阶段2（换障碍重导航）**：
- `--load-map scans/map_<seed>.npz --seed <新seed>` 启动
- static_grid = 加载的地图；obs_world = 新 seed 生成的障碍（世界真值，仅用于 is_obstacle_world/渲染，**不用于规划**）
- 机器人从起点出发：live_grid 初始空 → 边走边 scan → 射线清除旧障碍 + 发现新障碍
- 全局规划用 effective() → A* → Mover 执行 → 到达终点
- **验收标准**：机器人不重新探索（不重复扫描整个地图），直接从起点导航到终点，用时显著少于首次探索（目标 < 首次的 30%）

### 3.4 探索效率优化（目标1）

在双层地图基础上，探索阶段优化（ROS frontier 信息增益借鉴）：
1. **目标点信息增益**：`pick_gate` 打分加 `gain = 门附近未知格数量`（可新扫面积），不只终点导向
2. **目标保持**：连续帧门位置抖动时保持目标（防来回摇摆）——已有 back_blacklist 部分实现，可强化
3. **降扫描密度**：LIDAR_RAYS 120→60（探索初期开阔，密扫浪费）
4. **减少 bounce**：VO 局部避障（已有 todo，纳入本次）

验收：seed7 到达时间 < 649s（4m/s 版当前成绩），目标 < 500s。

## 五、绑架/随机位置（目标3）

- **随机采样**：在 50×50m 内随机 (x,y)，要求 `sample_hf(x,y)==ROAD_PIX`（不在墙里）且不在障碍内（参考 gen_obstacles 的 `_obs_hits_wall` 检查）——"注意别随机到墙里"
- **快速到达起点/终点**：
  - 方式1（简单）：直接给真值位置（仿真允许），加载地图 → A* 规划到目标 → 执行
  - 方式2（真实，加分）：**视觉标牌重定位**——机器狗看周围标牌（贴墙），识别通道 → 确定自己在哪 → 规划
- 验收：随机位置（避开墙）→ 到达终点，用时 < 60s（平均 50m 距离，走中间 + 已知地图应快）

## 六、标牌贴墙（响应主人反馈）

主人："标牌贴墙放置如何？别堵路。"

现状：上轮实验标牌立在**通道中心**（1m×1m 垂直 box），虽然 contype=0 不物理碰撞，但视觉/导航上挡路（机器人卡住实验已证实）。

改造：**标牌贴墙**——贴在通道墙内侧壁面（hfield 凸起墙的内侧面），或墙脚地面（低矮贴墙板）。
- 技术验证待做：EGL 渲染下墙内侧标牌是否可见（上轮发现墙顶标牌被 hfield 遮挡；墙脚标牌相机 1m 高平视可见）
- 方案：**低矮贴墙标牌**（0.3m 高 × 1m 宽，贴在墙脚，靠墙放置）——相机 1m 高能看到，不堵路
- 编码沿用 8 纯色 emissive（EGL 下可靠），贴墙后颜色识别逻辑不变

## 九、风险与备注

- **射线清除误删墙**：static_grid 单独存墙，live 清除只动 live 层 → 墙不会被删（双层保护）
- **旧障碍残留影响规划**：effective() 只信 live 障碍，旧障碍自然消失
- **走中间 vs 缺口通过**：窄缺口（~10°视角）走中间可能贴不到缺口——Voronoi 代价要留"缺口通行"例外（d 小时代价别太高），实现时验证
- **不新增世界真值作弊**：规划只用 SLAM 双层地图；obs_world 仅用于 is_obstacle_world（碰撞检测/渲染）
