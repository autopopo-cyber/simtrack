# M3+ 设计：无特权化改造（雷达感知 + 通过性 + ARM 轻量化）

> 日期：2026-08-08
> 状态：已获主人批准（"确定开始做吧，不用等我"）
> 目标：机器人只能知道它能感知到的物理真实，不要有特权；禁入区缩到 0.1m 或更小；RK3588 4核 ARM 能跑

## 背景

M3 里程碑达成（135s 走完 500m 蛇形+20 障碍，逼近物理极限）。主人验收后提出三个方向：
1. **审视特权信息**：机器人不能知道真实坐标/全图，只能靠激光雷达/视觉/里程计
2. **通过性**：墙/障碍边缘不可行区域缩到 0.1m 或更小，不碰撞前提下更贴墙
3. **轻量化**：更快算法，RK3588（ARM 4 核）能跑，甚至 1-2 核

## 特权信息审查结果

### ❌ 作弊点（需修复）
1. **blocked() 最后一行 is_obstacle_world()**——避障决策知道所有墙+障碍（真值），包括雷达看不到的墙后/转弯死角 → **改纯感知**
2. **--known-raw**——KNOWN_MAP 直读 track_clean 真值 = 偷看答案 → **标注测试模式，默认关**
3. **save_map()**——用 sample_hf（真值）标结构墙 → **改感知版（只存 grid 扫到的墙）**
4. **d.qpos 真实坐标**——狗知道自己位置（无里程计噪声）→ 仿真固有，本次不做（未来加噪声）
5. **完美 360° 雷达**——现实是前方 180° 前半球 + 有限线数 → **本次核心改造**

### ✅ 合理（物理事实判定）
- 碰撞统计 is_obstacle_world（是否真撞了）
- _bounce 撞墙检测、障碍生成验证

## 设计

### A. 雷达模型改造（核心）

```
现状：360° 单线（全向全知 = 特权）
改造：前方 180°（相对狗 yaw）+ 可配线数

  ↑ 狗朝 +x
  │
  └── 前方 180° 扇形（yaw±90°）──→ 点云 → scan 标 WALL
```

- **FOV**：`--lidar-fov`（默认 180°，相对狗朝向 yaw）
- **线数**：`--lidar-lines`（默认 1；多线 = N 条不同俯仰角 ±7.5°±15°...，2D 导航取最近——任一线命中 = 检测到）
- scan() 需要狗 yaw（从 d.qpos[2] 取）
- 狗只能知道前方 180° 内扫到的——身后/墙后 = 不知道

### B. blocked 纯感知

```python
def blocked(wx, wy):
    if 越界: return True
    if in_keepout(...): return True       # 感知墙禁入
    return gget_plan(...) == WALL         # 仅感知（雷达扫到的墙+障碍）
    # ❌ 去掉 is_obstacle_world（真值墙+真值障碍）
```

### C. save_map 感知版 + known-raw 默认关

- save_map：只存 grid 里雷达扫到的 WALL（感知地图），不用 sample_hf 真值
- --known-raw 默认 0（测试作弊模式），真实流程：探索→save_map→load_map

### D. 禁入区缩小

- 当前 KEEP_CELLS=1（10cm）→ 试半格 0.05m 或只保留碰撞余量（通过性更强）
- 障碍收窄已保证缝隙 ≥0.7m，禁入区缩小进一步放宽

### E. ARM 轻量化

- 前方 180° 自动省 50% 扫描计算
- OBS_CELLS 已有（障碍判定 O(1)）
- scan 向量化（numpy 批量射线替代 Python 循环）——后续单独任务

## 调试节奏（主人：慢慢调试）

每步独立验证，不破坏已有成绩：
1. 雷达改造（前方 180° + 线数）→ 跑通确认感知正确
2. blocked 纯感知 → 跑通确认无特权（可能早期小碰撞，靠碰撞统计学习）
3. save_map/known-raw 修复
4. 禁入区缩小 → 通过性测试
5. ARM 优化（向量化）→ 性能测试

## 验收标准

- 狗只用雷达感知决策（无真值特权：blocked 不读 is_obstacle_world）
- 前方 180° 雷达正常导航到终点
- 禁入区 ≤0.1m，通过性不降（bounce/collision 不恶化）
- RK3588 单核可运行（每步计算量 ≤ 当前 1/2）
