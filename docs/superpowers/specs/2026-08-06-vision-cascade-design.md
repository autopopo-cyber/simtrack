# 视觉二维码标牌系统：金字塔级联粗筛 + 2m 贴墙标牌 — 设计

> 2026-08-06 · 主人指令：①标牌放大长宽 2 倍（狗视角够用）②金字塔 coarse-to-fine：低分辨率无特征则跳过全部高分辨率检测

## 背景

机器狗视觉定位系统使用 30 个 ArUco 二维码标牌（DICT_7X7）。当前实现每帧跑 6 档分辨率金字塔（0.25x~3x），**无标牌帧 25.1ms 全部浪费**（导航中 95%+ 帧看不到标牌）。

## 目标

1. 标牌 1m → **2m**（长宽 2 倍），狗视角更易识别、识别距离更远
2. 金字塔**级联粗筛**：低分辨率对比度特征不足 → 跳过全部高分辨率检测
3. 保持识别率不降（有标牌帧必须全命中）

## 关键发现（实测）

| 项 | 数值 |
|---|---|
| 无标牌帧 Laplacian 能量（0.25x） | 23 ~ 84 |
| 有标牌帧 Laplacian 能量（0.25x） | 231 ~ 1684 |
| 判别阈值 | **200**（10 倍间隔，零重叠） |
| 粗筛成本 | ~0.5ms（resize + Laplacian） |
| 完整金字塔成本 | ~25-30ms |

**为什么不用 ArUco 候选做粗筛**：0.1x/0.25x 下地形轮廓误报（无标牌 1-4 候选）、近距大码漏报（缩太小格子消失）。拉普拉斯能量 10 倍间隔零误判。

**标牌必须贴三面墙场景**（通道两侧纵墙 + 尽头横墙）：单面墙时标牌背景空旷，ArUco 边界分离失败；三面墙闭合后标牌贴横墙内表面（凸出 0.3m），全部距离识别成功（x=20 距 29.6m 仍 scale=0.5 命中）。

## 架构

```
VisionLandmark.scan_once(step)
  ├─ 渲染相机帧（GPU ~33ms）
  ├─ [粗筛] resize 0.25x + cv2.Laplacian → energy
  │    energy < 200 → return []（无黑白高对比特征，跳过全部）
  │    energy ≥ 200 → 继续
  └─ [精识别] 6 档金字塔 ArUco（0.25/0.5/1.0/1.5/2.0/3.0）
       一步内同标牌去重
```

## 改动

### landmarks.py
- `LM_HALF` 0.375 → **1.0**（2m 标牌，平面 size 半尺寸）
- 标牌贴**横墙内表面**（x=49/1 交替），凸出墙面 0.3m，中心离地 1.0m（= 相机高度）
- 场景加**三面 box 墙**（通道两侧 + 尽头横墙，contype=0 纯可视化）
- 保留 emissive 材质（hfield 地形暗，非 emissive 对比不足）

### vision_landmark.py
- `_detect_pyramid` 前加 `_coarse_gate`：0.25x Laplacian 能量阈值 200
- 金字塔尺度过小时（<60px）跳过逻辑保留

### algo3_headless.py
- 已导入 BOT_Z / landmark_xml，XML 墙段接入三面墙

## 验收标准

1. 无标牌帧：粗筛跳过，单帧检测 < 2ms（原 25ms）
2. 有标牌帧（2m 标牌，距离 5-30m）：金字塔命中 ID
3. 导航 30s：标牌识别数与落地前不降
4. 能量阈值 200 零误判（无标牌 <200，有标牌 >200）
