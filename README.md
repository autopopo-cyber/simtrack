## 一、项目是什么

MuJoCo 仿真中，机器狗在 **50×50m 蛇形迷宫**（10 条水平通道 + U 型弯，路径约 **476m**）里自主导航。核心约束（主人铁律）：**现实中不允许碰撞**——运动学约束避障（前瞻测距 + 制动约束 v≤√(2·A_DECEL·d)），碰撞=0。**不作弊**——SLAM 建图，不用世界真值规划。

## 三、当前系统能力（2026-08-06 实测）

### 导航
- **探索模式**（SLAM 自建图）：seed7 540s → 覆盖 52%、到通道 4；全程估算 ~1000s
- **已知地图模式**（--load-map + A*）：540s → 通道 5（55%）；全程估算 ~900s
- **碰撞全 0** ✅（运动学约束生效，所有测试）
- 速度 ~120-200 步/s（理论 200；瓶颈 bounce 70+ 次/540s——斜墙）

### 视觉二维码标牌
- **10 个标牌**（每通道 1 个）立在通道中心线终点端，2m×2m，DICT_7X7，中心离地 1m = 相机高度
- **图像金字塔多尺度**（0.25x~3x 六档）+ **级联粗筛**（0.25x Laplacian 能量 <200 跳过 → 0.3ms vs 25ms）
- 相机 roll 修正：`euler="0 -1.5708 -1.5708"`（天空在上、地面在下）
- 识别率：10/10 标牌双方向全绿；导航中持续识别

### 迷宫与障碍
- 476m 蛇形迷宫**完全连通**（BFS 23.5 万格全通，起点→终点无墙阻断）
- 障碍：**固定位置**（seed 决定，seed7=10 个，半径 0.5m 圆柱）；`--obs-reseed` 可运行中换位置
- 另有 **45° 薄斜墙**（hfield 地形自带，0.1m 厚）——bounce 主要来源

## 七、本轮收获（2026-08-05 ~ 08-06）

1. **MuJoCo hfield 世界模型**：`size="25 25 4 2"` → 表面高度 = 2+4×(灰度/255)。通道(128)=4.008m——**机器狗 body 必须站表面上方**，否则相机在地底下全黑（多轮"全黑/检测不到"的元凶）
2. **MuJoCo 相机 euler 是 extrinsic xyz**：`euler="0 -1.5708 0"` 时 right=+z（天空在水平方向，画面 roll 90°）→ 必须 `euler="0 -1.5708 -1.5708"` 才 up=+z 天空在上
3. **plane 纹理旋转**：绕 y 旋转（横墙）纹理可靠，绕 x 旋转（侧墙）纹理异常——标牌只能贴横墙
4. **ArUco 需要闭合背景**：标牌在开口区（无墙背景）边界分离失败 → 加背景板（后面 0.6m 深色 box）
5. **级联检测**（主人思路）：低分辨率 Laplacian 能量判别"有无特征"，无特征跳过全部高分辨率——无标牌帧 25ms→0.3ms
6. **薄斜墙漏扫**：LIDAR_RAYS=120 在 15m 处射线间距 0.78m > 斜墙 0.1m 厚 → 漏扫 → A* 认为可走 → 执行层撞墙 bounce。360 射线修复
7. **A* 扩展上限**：蛇形迷宫全程 A* 需扩展 >3 万格（BFS 全图 23.5 万）——ASTAR_MAX_EXPAND 30000→250000
8. **GPU 驱动修复**：内核 580.159 vs 用户库 580.173 不匹配 → llvmpipe 软渲染 3.5s/帧 → 重载驱动 33ms/帧

## 八、本轮教训（含跑偏审视）

1. **文档没跟上开发**（主人 08-06 晚指出"忘了好多东西"）——两天的高密度工作全在会话上下文里，pitfalls 停在 08-05，mystory 停在更早。**教训：每完成一个阶段立即沉淀文档**，不能攒到最后。
2. **加几何前先验证地图真实结构**——box 墙"分界墙"加满了 x∈[0,50] 全程 + 横墙，结果**堵死所有 U 型弯**（主人一眼看出）。教训：先跑连通性测试（BFS/路径采样）再改场景。
3. **相机取景 vs 纹理 bug 误判**——"二维码渲染不完整"查了十几轮纹理方向/翻转/UV，实际是**相机 1.5m 太矮取景切掉下沿**。教训：先排除取景/相机参数，再怀疑纹理。
4. **单测环境与真实场景差异**——标牌单测识别成功，集成到迷宫失败（缺闭合背景/嵌墙/被墙挡）。教训：集成测试从第一天就带完整场景。
5. **渲染类功能必须默认关**（早期教训）：EGL llvmpipe 3.5s/帧拖死导航——`--vision/--landmarks` 默认关，性能问题解决后再开。
6. **光提速度没用**（早期教训）：必须配"近墙限速"（d_clear<2m 限速 1.5），开阔提速、狭窄减速。
