## 〇、探索哲学（核心思想 · 2026-08-09 主人定义）

**探索不是把地图画完再走，而是不断发现门、确认门后到底是什么的过程。**

- **门（gate）= 未知前沿**：已知区域与未知区域的边界。**每个门都可能是疑似终点**——答案隐藏在未知后
- **探索循环**：雷达扫描建图 → 发现门 → 走向门 → **确认门后是什么**（新区域 / 死胡同 / **终点**）→ 继续
- **走迷宫的方式**：不是"找墙上的缺口钻"，而是**面向每一个未知前沿，去确认它后面到底是什么**——终点可能就在任何一个门后面
- **效率关键**：带着目标穿行未知（advance 评分朝终点推进），不是随机扫；确认过的门 = 已知，未确认的门 = 下一个疑似终点

### 本轮修复的关键根因（各卡死/耗时场景逐一实测定位）
1. **幽灵门**：雷达 0.1m 步进跨过 <0.1m 真缝（45° 斜边端点）→ 墙另一侧标 FREE 产生不可达门 → **像素级 DDA 扫描**（0.025m=1px 步进）根治
2. **bad_gates 黑名单 key 错位**：存聚类质心 vs 过滤原始门格 → 形同虚设 → **按门格集合拉黑** + 限量 FIFO + 0 门清空
3. **墙脸伪前沿门**：掠射把墙面格标 FREE、墙背行 UNKNOWN → 门后是墙体 → **墙厚先验**（命中点向里 2 格也标墙）+ 开阔前沿 5x5 过滤
4. **BFS 虚空漫游 + 跳步飞越过渡格**：边界无检查 + 中间格不进 visited → 边界检查 + 过渡格补评+came_from 补录
5. **bounce 自锁**：净空 0.4m 的目标对齐方向反复撞墙 → 逃逸方向净空 ≥0.8m
6. **障碍圈笼**：探索模式安全圈写 static 但 gget_plan 不读 → 圈不可见；改写 live（射线维护：障碍在圈不消，移走即清）+ 狗在圈外才写
7. **DWA 自旋锁**：v≈0 原地转时 heading 无信号，smoothness 锁死大 ω → v<0.1 时 heading 改用"horizon 末朝向 vs 目标"
8. **碰撞检测误报**：格查表 0.8m+量化把 0.9m 安全通过记为碰撞 → 精确圆 0.7m
9. **门即达**：门是"看的目标"不是"踩的目标"（3m 内即消耗，雷达早扫过门后）；但**直奔终点的路径必须真到达**（path_is_goal 不提前消耗）
10. **BACK 限流**：无路标可达时全图 A* 风暴烧穿计算 → 每次 20 个路标 + 400 步一次

## 七、本轮收获（08-05 ~ 08-07）

1. **撞障碍学习闭环**（08-07 M2）：STOP识别→escape(可走最远)→写安全圈(static_grid)→HPA重建→重规划。每障碍撞 1 次即学会绕行，混合 20 全程 bounce 1
2. **动态安全距离**（08-07 主人指令）：物理边界固定 0.7m + v_brake 制动约束自适应——接近障碍自动减速，低速挤窄缝。**错误做法**（刹车距离塞进碰撞判定）会死锁：狗离障碍 1.2m 加速到 3m/s 安全距离 1.26m > 1.2m → 永远无法加速
3. **blocked 精确圆判定**（08-07）：去 5×5 邻域 +0.283m 过保守冗余——窄缝（中心距 ≥1.4m）可挤过
4. **HPA\* 分层寻路**（08-07）：全程 A* 50.8s → HPA* 0.38ms（13 万倍）。主人方法论"先移植成熟算法"的胜利
5. **yaw 控制变量直接写回物理**（08-07）：`self.yaw = d.qpos[2]` 读回导致每步转向被重置——所有 bounce/卡死的终极根因，修复后 bounce 94→0
6. **距离场 BFS 取 min**（08-07）：`n if n<v else (w if w<v else v)` 忽略更小 w——墙邻格被误判开阔 49 倍
7. **MAX-pool y 轴 flip**（08-06）：图像 row0=y=50m 顶部，格 gy=0=y=0m——不翻转则墙位置上下颠倒（早期所有诡异卡点的根源）
8. **薄斜墙漏扫**（08-06）：LIDAR_RAYS=120 在 15m 处射线间距 0.78m > 斜墙 0.1m 厚 → 漏扫。360 射线修复
9. **级联检测**（08-06）：低分辨率 Laplacian 能量判别"有无特征"——无标牌帧 25ms→0.3ms
